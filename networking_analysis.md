# Week 6 Task 1: Mobile Application Networking Analysis

## 1. WhatsApp
| Component | Details |
|-----------|---------|
| **Client** | WhatsApp mobile app (Android/iOS) |
| **Server** | Meta/Facebook servers (WhatsApp backend) |
| **Data Exchanged** | Messages, media files, contact lists, online status, read receipts, voice/video calls |

## 2. Facebook
| Component | Details |
|-----------|---------|
| **Client** | Facebook mobile app |
| **Server** | Meta/Facebook servers globally distributed |
| **Data Exchanged** | Posts, comments, likes, friend lists, profile information, images, videos, advertisements |

## 3. Uber
| Component | Details |
|-----------|---------|
| **Client** | Uber passenger/driver app |
| **Server** | Uber cloud servers (AWS) |
| **Data Exchanged** | GPS location, ride requests, driver availability, payment information, trip history, real-time tracking |

## 4. M-Pesa
| Component | Details |
|-----------|---------|
| **Client** | M-Pesa mobile app/USSD interface |
| **Server** | Safaricom/Vodafone servers (secure banking infrastructure) |
| **Data Exchanged** | Phone number, PIN, transaction amounts, balance inquiries, merchant payments, transaction receipts |

## 5. YouTube
| Component | Details |
|-----------|---------|
| **Client** | YouTube mobile app |
| **Server** | Google servers (YouTube infrastructure) |
| **Data Exchanged** | Video streams, search queries, recommendations, user subscriptions, watch history, comments, likes |
