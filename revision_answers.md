# Week 6-7 Revision Questions - My Answers

### 1. What is mobile application networking?
Mobile networking is how apps talk to the internet to send and receive data. When you send a WhatsApp message, it goes through the internet to WhatsApp's servers and then to your friend's phone.

### 2. Explain client-server architecture.
Think of it like ordering food:
- The client is you (the customer) - you make a request
- The server is the kitchen - they prepare what you asked for
- The network is the waiter - carries the request and the food back

### 3. Define API.
API is like a menu at a restaurant. It tells developers what requests they can make to a server and what they'll get back.

### 4. What is JSON?
JSON is a format for sending data over the internet. It looks like this: {"name": "Jacob", "course": "BIT"}

### 5. Differentiate GET and POST requests.
GET gets data from server, POST sends data to server. GET has data visible in URL, POST has data hidden in the request body.

### 6. Define SQLite.
SQLite is a database that sits on your phone - like having a mini Excel on your device.

### 7. What is Firebase?
Firebase is Google's app development platform with user login, cloud database, storage, and push notifications.

### 8. Explain CRUD operations.
- Create (INSERT): Add new data
- Read (SELECT): View existing data
- Update (UPDATE): Change existing data
- Delete (DELETE): Remove data

### 9. Compare local and cloud storage.
Local storage is on your phone (fast, free, works offline). Cloud storage is on the internet (syncs everywhere, needs internet, costs money).

### 10. Importance of databases in mobile apps.
Databases keep data when you close the app, work offline, make apps faster, remember preferences, keep data private, and sync across devices.
